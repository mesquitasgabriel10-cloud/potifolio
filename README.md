## 🌟 Sobre o Projeto

O **PortfolioHUB** foi criado com o objetivo de organizar e armazenar projetos acadêmicos e pessoais utilizando práticas de versionamento com Git e GitHub.

Este repositório funciona como um portfólio profissional, permitindo o compartilhamento de projetos, documentação e experiências na área de tecnologia.
